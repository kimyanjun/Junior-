Learn CSS

Learn how to style your HTML websites with CSS.

What is CSS?

CSS stands for Cascading Style Sheets. CSS is used to make HTML websites look better.

With CSS you can change:

  • Colors
  • Fonts
  • Backgrounds
  • Spacing
  • Buttons
  • Layouts

1. Changing Text Color

You can use the color property.

h1 {
    color: blue;
}

This text is blue

2. Changing Background Color

Use background-color to change the background.

body {
    background-color: lightblue;
}
This box has a background color.

3. Changing Font Size

Use font-size to change the size of text.

p {
    font-size: 20px;
}

This text is 20 pixels.

4. Styling Buttons

You can use CSS to make buttons look attractive.

button {
    background-color: blue;
    color: white;
    padding: 10px;
    border-radius: 5px;
}

5. CSS Classes

A class lets you apply the same CSS style to different HTML elements. 

HTML:

<p class="important">
    Learn CSS!
</p>

CSS:

.important {
    color: red;
    font-size: 24px;
}

Learn CSS!

HTML + CSS Together

Here is a simple example:

<h1 class="title">My Website</h1>

<style>
.title {
    color: purple;
    text-align: center;
}
</style>
