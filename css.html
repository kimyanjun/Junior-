Learn CSS

Learn how to style your websites with CSS.

What is CSS?

CSS stands for Cascading Style Sheets. It is used to style and design HTML websites.

CSS can change:

  • Text colors
  • Background colors
  • Font sizes
  • Spacing
  • Buttons
  • Layouts

1. Changing Text Color

The color property changes the color of text. 

h1 {
    color: blue;
}

This text is blue

2. Changing Background Color

The background-color property changes the background. 

body {
    background-color: lightblue;
}
This box has a background color.

3. Changing Font Size

The font-size property changes the size of text. 

p {
    font-size: 20px;
}

This is an example of bigger text.

4. Styling Buttons

CSS can make buttons look better. 

button {
    background-color: blue;
    color: white;
    padding: 10px;
}

5. CSS Classes

Classes allow you to apply CSS styles to specific HTML elements. 

HTML:

<p class="important">
    This is important.
</p>

CSS:

.important {
    color: red;
}

This is an important message.
