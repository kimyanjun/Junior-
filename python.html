Learn Python

Start your journey into the world of Python programming.

What is Python?

Python is a popular programming language that is easy to learn and powerful to use.

Python can be used for:

  • Web Development
  • Artificial Intelligence
  • Games
  • Data Science
  • Automation

1. Your First Python Code

You can use Python to display text using print().

print("Hello, World!")

Output: Hello, World!

2. Python Variables

Variables are used to store information. 

name = "Ray"
age = 16

print(name)
print(age)

3. Python Numbers

Python can perform mathematical calculations. 

number1 = 10
number2 = 5

answer = number1 + number2

print(answer)

Output: 15

4. Python If Statements

If statements help a program make decisions. 

age = 18

if age >= 18:
    print("You are an adult")

5. Python Loops

Loops allow you to repeat code. 

for number in range(5):
    print(number)

Output: 0 1 2 3 4

Keep Learning!

Python is a great language for beginners. Keep practicing and building projects to improve your programming skills.
