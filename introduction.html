Introduction to Websites

Learn how websites are created using HTML and CSS.

What is a Website?

A website is a collection of web pages that can be accessed using a web browser such as Chrome, Firefox, or Edge.

Websites are commonly created using HTML, CSS and JavaScript.

What is HTML?

HTML stands for HyperText Markup Language. It is used to create the structure and content of a webpage.

Example of HTML:

<h1>Welcome to My Website</h1>
<p>This is my first webpage.</p>

What is CSS?

CSS stands for Cascading Style Sheets. It is used to make webpages look attractive.

CSS can change colors, fonts, spacing, backgrounds, buttons and the layout of a webpage.

Example of CSS:

h1 {
    color: blue;
}

p {
    font-size: 18px;
}

How HTML and CSS Work Together

HTML creates the structure of the webpage, while CSS controls how the webpage looks.

This is HTML + CSS

HTML creates this text and CSS styles it.
