Learn How to Build Websites

Websites are mainly built using HTML and CSS. Learn what each language does and how they work together.

HTML

HTML stands for HyperText Markup Language. It is used to create the structure and content of a website.

What can you learn with HTML?

  • Headings
  • Paragraphs
  • Images
  • Links
  • Buttons
  • Forms
Learn HTML

CSS

CSS stands for Cascading Style Sheets. It is used to style and design your website.

What can you learn with CSS?

  • Colors
  • Fonts
  • Spacing
  • Layouts
  • Animations
  • Responsive design
Learn CSS

What is JavaScript?

JavaScript is a programming language used to make websites interactive and dynamic. It allows you to create buttons, animations, calculators, games, and many other features.
