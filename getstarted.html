Introduction to Websites

Welcome! In this lesson, you will learn the basics of websites and how they are created.

What is a Website?

A website is a collection of web pages that you can visit using a web browser such as Chrome, Firefox, or Safari.

Websites can contain text, images, videos, buttons, links, forms, and many other things.

How Are Websites Made?

Most websites are built using three important technologies:

HTML

HTML creates the structure and content of a webpage.

CSS

CSS controls the appearance and design of a webpage.

JavaScript

JavaScript adds interaction and behavior to a webpage.

Your First Webpage

Here is a simple HTML example:

<h1>Hello World!</h1>
<p>Welcome to my website.</p>

The h1 creates a heading, while the p creates a paragraph.
