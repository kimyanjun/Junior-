What is JavaScript?

JavaScript is a programming language used to make websites interactive. HTML creates the structure, CSS controls the appearance, and JavaScript adds actions and behavior.

Example 4: If Statement

An if statement allows JavaScript to make decisions. 

let age = 18;

if (age >= 18) {
    console.log("You are an adult.");
} else {
    console.log("You are under 18.");
}
